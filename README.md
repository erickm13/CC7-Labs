# CC7-Labs - Sistemas Operativos

Laboratorios del curso de Sistemas Operativos (CC7).

## Labs

- **Lab1**: Hello World con QEMU
- **Lab2**: Calculadora (operaciones básicas)
- **Lab3**: Manejo de Interrupciones (BeagleBone)
- **Lab4**: Creación y Gestión de Procesos

## Estructura

```
lab1/  - Hello World QEMU
lab2/  - Calculadora
lab3/  - Interrupt Handler (BeagleBone)
lab4/  - Process Management
```

## Compilar y ejecutar

Cada lab tiene su propio script `build_and_run.sh`.

```bash
cd labX/.../Code
./build_and_run.sh
```
